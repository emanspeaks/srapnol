# Errors versus exits

Zig errors are reserved for misuse and resource failure (`ValidateError`,
`OutOfMemory`, `InvalidOption`); every algorithmic outcome is an `Exit` value whose
integer is the snOptA `INFO` code, and `State` is always left holding the last
iterate. A misuse detectable at `init` never reaches the iteration loop, so the loop
can assume a validated problem and assert only in safe builds.
