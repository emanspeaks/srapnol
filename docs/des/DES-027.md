# Dense factors first

The reference problems have `n <= 5` and `nf <= 4`; a dense basis and full-memory
Hessian make the first correct implementation small and debuggable, and the factor
interfaces are designed so the sparse basis and limited-memory Hessian are drop-ins.
The dense `R` is permanent: SQOPT keeps it dense too, and it is why `superbasics_limit`
exists.
