# Callback wrapper

A thin layer between the loop and `Problem.eval` sequences statuses (`.first` once,
`.normal`, `.last` once after termination with `f == g == null`), screens `f` for NaN
and infinity (mapped to `error.Undefined`), maps `error.Abort` to exit 71, counts
function and Jacobian evaluations for `Result`, and scatters `G` values through the
pattern permutation. Compile-time `Problem.wrap` generates the typed thunk so Zig
callers pay no runtime dispatch beyond one indirect call.
