# Sparse storage and products

\(A\) and \(G\) are converted at `init` from coordinate lists to compressed-column
storage. The permutation from pattern order to CSC order is kept so callback \(G\)
values are scattered into place without searching. Matrix-vector and transposed
products use FMA over contiguous value runs; gathers and scatters are scalar.
