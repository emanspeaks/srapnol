# Build, packaging, and delivery

`build.zig` delegates to `build/__root__.zig`, which uses `rstd`'s build utilities:
steps `install` (the `srapnol-test` executable), `run`, `test` (the module's unit
tests with `build_options` and `rstd` wired in), `docs` (API documentation), and,
from phase 9, `shim` (the C shared library and generated `srapnol.h`). The package is
consumed through `build.zig.zon`, whose `paths` list (`build.zig`, `build.zig.zon`,
`build`, `src`, `LICENSE`) is the delivered file set; the Zig toolchain version and
the `rstd` commit are pinned in the Version Description Document of each release.
