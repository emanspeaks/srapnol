# Workspace

`init` sizes one arena from `n`, `nf`, `nnz(A)`, `nnz(G)`, and the options: CSC
storage for `A` and `G` (`nnz` values plus `n + 1` pointers each), the dense basis
(`m^2` doubles), `R` (`superbasics_limit^2 / 2` doubles), Hessian memory (dense
`n_nonlinear^2 / 2` or `2 * hessian_updates * n_nonlinear`), and `O(n + nf)` vectors
for the iteration, slacks, multipliers, bounds, scale factors, and line-search trial
points. The bound is documented in the Software Data Dictionary and checked by the
allocation procedure. No CPU, bus, or I/O budget applies.
