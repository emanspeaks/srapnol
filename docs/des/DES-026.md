# Execution sequence

Single-threaded, synchronous, and re-entrant per instance: `init` (validate, convert,
scale, allocate) then `solve` (feasibility phase, major loop, final callback, write
back) then `deinit`. No interrupts, timers, or signals are used; no thread is created
inside a solve, so independent instances may run on different threads without shared
state. Execution time is proportional to major iterations times (QP minors times
\(O(n_S^2)\) plus solves with \(B\)) plus callback cost.
