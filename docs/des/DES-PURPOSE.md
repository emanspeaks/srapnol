# Purpose

This Software Design Description (SwDD) records the architecture and component design
of `srapnol` and the decisions that turn SNOPT's published design into this
implementation. Content follows NASA-HDBK-2203 topic 5.13. Every design item links to
the SRS items it implements, giving requirements-to-design traceability (NPR 7150.2D
SWE-052); `references` point at the source files that realize the component.
