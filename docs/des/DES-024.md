# Options

`Options` is a plain struct whose fields mirror SNOPT keywords with SNOPT defaults
(tabulated in the Software Data Dictionary). `Solver.init` validates ranges
(non-negative tolerances, `linesearch_tolerance` in `[0, 1)`, nonzero limits) and
resolves `superbasics_limit == null` to `min(500, n + 1)`.
