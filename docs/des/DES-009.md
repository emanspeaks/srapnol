# Quality-attribute views

- Performance: SIMD kernels for dense vectors, triangular solves, rotations, and
  contiguous sparse runs; no allocation in the loop; dense `B` and `R` sized once.
- Determinism: no randomness, no threads inside a solve, no dependence on iteration
  timing; fixed seed for pattern estimation.
- Testability: every kernel has a scalar twin; the test rig has an independent
  Jacobian oracle; reference problems assert KKT conditions before any solve.
- Portability: pure Zig, target-agnostic vector width via `suggestVectorLength`.
- Maintainability: one module per component, requirement UIDs cited at declarations.
