# Internal interfaces

- Basis factor: `factor(B)`, `solve(rhs)`, `solveTranspose(rhs)`, `replaceColumn(j, col)`,
  `conditionEstimate()`, `needsRefactor()`; errors signal singularity for repair.
- Kernels: every `vec.zig` kernel has the signature of its scalar twin and takes
  slices; no kernel allocates.
- Sparse matrix: `mulVec(x, y)`, `mulVecTranspose(y, x)`, `scatter(pattern_vals)`,
  column iteration for the QP's `S` products.
- QP to driver: `solveQp(workspace, x, s, pi, H, D) -> QpResult{ d_x, d_s, pi_hat,
  status }`.
- Log: `major(line: MajorLine)`, `minor(line: MinorLine)`, `summary(result)`, each a
  no-op with a null writer.
External interfaces are the SRS section 3 items; the C ABI data elements are in the IDD.
