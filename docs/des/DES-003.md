# External interfaces

Four external interfaces: the Zig API (types re-exported from `__root__.zig`), the
evaluation callback (a `*const fn` plus opaque context; `Problem.wrap` generates the
thunk at compile time), the allocator passed to `Solver.init`, and an optional
`std.Io.Writer` for diagnostics. The C ABI (section 7) is an adapter over the Zig API
and adds nothing to the core. There are no file, network, or hardware interfaces.
