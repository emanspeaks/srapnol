# Why pure Zig

A C or Fortran core would bring a second toolchain, an FFI boundary in the hot loop,
and a foreign build into every consumer; Zig gives explicit allocation, portable SIMD
through `@Vector`, comptime callback adaptation, and cross-compilation for the
portability matrix. The C ABI is exported from Zig, so C consumers get the same
determinism and allocation policy.
