# Elastic mode

If the linearized rows are infeasible, each nonlinear row `i` gets elastics
`v_i, w_i >= 0` and its equality becomes `F_i + J_i d - s_i + v_i - w_i = 0`, with
`gamma (v_i + w_i)` added to the objective, so the QP is always feasible. `gamma`
starts at `elastic_weight` and grows by a fixed factor, up to a cap, each time the
elastic solution still violates the true constraints; if the infeasibility cannot be
driven to zero the solve ends with 13 or 14, and 15 if a QP cannot be made feasible.
