# The acceptance problem is hostile by design

The three-bar truss is small but has variables of \(10^{-4}\), rows of \(10^{8}\),
Jacobian entries of \(10^{12}\), and a multiplier of \(10^{-8}\). Unscaled, the dual
test asks \(\nabla f\) (order \(10^{4}\)) to be cancelled by \(J'\pi\) to \(10^{-6}\)
absolute, a relative \(10^{-10}\); achievable only if merit, penalty updates, and
Hessian scaling do not amplify round-off. The closed form has the single active row
`sigma3 = -sigma_allow`, so once the active set is identified one exact QP step lands
on the constraint curve and the rest is Newton-like along it; a correct implementation
converges in well under 20 major iterations from \((5 \times 10^{-4}, 5 \times
10^{-4})\). The tests assert unscaled quantities on `State`, forcing the implementation
to get scaling right rather than loosen tolerances.
