# The acceptance problem is hostile by design

The three-bar truss is small but has variables of `1e-4`, rows of `1e8`, Jacobian
entries of `1e12`, and a multiplier of `1e-8`. Unscaled, the dual test asks `grad f`
(order `1e4`) to be cancelled by `J' pi` to `1e-6` absolute, a relative `1e-10`;
achievable only if merit, penalty updates, and Hessian scaling do not amplify
round-off. The closed form has the single active row `sigma3 = -sigma_allow`, so once
the active set is identified one exact QP step lands on the constraint curve and the
rest is Newton-like along it; a correct implementation converges in well under 20
major iterations from `(5e-4, 5e-4)`. The tests assert unscaled quantities on
`State`, forcing the implementation to get scaling right rather than loosen
tolerances.
