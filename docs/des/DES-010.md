# Problem transformation

1. **Slacks.** Introduce `s` in `R^nf` and write `F(x) - s = 0`, `f_low <= s <= f_upp`.
   Every general constraint becomes an equality and every inequality a bound; the
   combined vector `(x, s)` has `n + nf` components and the constraint matrix at a
   point is `[J  -I]`.
2. **Objective row.** Row `obj_row` leaves the constraint set: its value is the
   objective, its slack is unused, its bounds are ignored. With `obj_row == null` the
   objective is identically zero.
3. **Partition.** Rows with no `G` entries are linear rows; columns with no `G`
   entries are linear variables. Only nonlinear rows enter the merit function and
   elastic mode; only nonlinear variables carry Hessian curvature.
4. **Infinite bounds** are dropped; a variable free on both sides starts nonbasic
   at `x0`.
5. **Constant rows** (no entries at all) are checked once against their bounds.
