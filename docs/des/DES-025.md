# C ABI shim

`src/cabi.zig` exports `extern "C"` functions over opaque handles
(`srapnol_problem`, `srapnol_solver`, `srapnol_state`) and `extern` structs mirroring
`Options` and `Result`; the callback is a C function pointer with `void *ctx`, and the
shim wraps it in an `EvalFn` that maps negative return codes to `error.Undefined` and
`error.Abort`. Every entry validates its inputs and returns an integer code; `Exit`
codes pass through unchanged. Memory comes from a C-allocator adapter chosen at
`srapnol_solver_init` (the caller may pass `malloc`/`free` pairs). The build step
`zig build shim` produces the shared library and `srapnol.h`. Full element definitions
are in the IDD.
