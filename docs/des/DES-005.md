# Reuse and dependencies

No third-party or COTS component is used. The Zig standard library supplies
allocation, SIMD vectors, sorting, and I/O abstractions; `rstd` supplies build
utilities now and, at integration, `rstd.linalg.matlab` kernels where they are a strict
improvement over the local ones. Algorithms are re-implemented from the published
papers; no SNOPT source is used.
