# Quasi-Newton Hessian

\(H\) approximates the Hessian of \(L = f - \pi'F\) over the nonlinear variables.
After a step with \(\delta = x_{k+1} - x_k\) and
\(y = \nabla L(x_{k+1}, \pi_{k+1}) - \nabla L(x_k, \pi_{k+1})\), BFGS applies when
\(y'\delta \ge \sigma \delta'H\delta\); otherwise GMS's modified \(y\) adds
\(J'D(F_{k+1} - F_k)\), and the update is skipped if that still fails; repeated skips
reset \(H\) to a scaled identity.

Limited memory (default): \(H = H_0 + \sum_j (v_j v_j' - u_j u_j')\) with self-scaled
\(H_0 = \sigma_0 I\) and `hessian_updates` pairs, flushed and rescaled when full;
products cost \(O(n_{nonlinear} \cdot \mathrm{pairs})\), and \(R\) is built column by
column from them. Full memory: a dense Cholesky factor of \(H\) with the rank-two
BFGS update applied as two rank-one updates; the first target since the reference
problems have \(n \le 5\).
