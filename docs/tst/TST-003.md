# Jacobian oracle self-test

**Purpose.** Confirm the test rig's independent central-difference Jacobian checker accepts a correct `G` and flags a wrong value, a nonzero outside the declared pattern, and a linear term leaking into `f`.

**Grouping.** Test-tool validation.

**Software version.** The version under test is recorded in the Software Test Report; this procedure applies from 0.1.0.

**Prerequisites.** Repository checked out at the version under test; toolchain and `rstd` per STP section 4.

**Steps.**

1. Run `zig build test` (toolchain per STP section 4).
2. Observe the `jacobian oracle:` tests and `evalFull adds the linear part`.

**Inputs.** `f = [x0 x1, x0^2]` with `F_1 = f_1 + 3 x1`, evaluated at `(1.5, -0.75)` with one deliberate defect at a time.

**Expected results.** Correct `G` passes at `1e-8`; each defect is reported at the expected entry or `(row, col)`; `evalFull` reproduces `F`.

**Pass/fail criteria.** Pass when every listed test reports success. A test that reports skipped counts as a pass only while every requirement it verifies has `status: pending` in SRS; otherwise the procedure fails.

**Rerun.** Repeatable without cleanup; the procedure is deterministic and has no external state.

**Zig test names.**

- `jacobian oracle: passes a correct G`
- `jacobian oracle: flags a wrong derivative value`
- `jacobian oracle: flags a nonzero outside the declared pattern`
- `jacobian oracle: flags linear terms leaking into f`
- `evalFull adds the linear part`
