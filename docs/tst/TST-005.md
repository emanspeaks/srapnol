# Requirement citation inspection

**Purpose.** Confirm that code fulfilling a requirement cites its identifier and that every SRS `references` entry resolves to such a citation.

**Grouping.** Inspection.

**Software version.** The version under test is recorded in the Software Test Report; this procedure applies from 0.1.0.

**Prerequisites.** Repository checked out at the version under test; toolchain and `rstd` per STP section 4.

**Steps.**

1. Run `zig build test` (toolchain per STP section 4).
2. Search `src/` for `SRS-` citations; for each SRS item with a `references` entry, confirm the keyword appears in the referenced file at the declaration that fulfils the requirement; confirm Doorstop validation reports no missing references.

**Inputs.** The source tree and the SRS tree at the same commit.

**Expected results.** Every referenced keyword is found; no citation names a retired identifier.

**Pass/fail criteria.** Pass when Doorstop validation reports no reference errors and a manual scan finds no legacy identifiers.

**Rerun.** Repeat at every release and whenever SRS items are added or renumbered.
