# Hock-Schittkowski 15

**Purpose.** Confirm a solve from an infeasible start reaches the optimum with a row and a bound active together and the documented multipliers.

**Grouping.** Requirements verification.

**Software version.** The version under test is recorded in the Software Test Report; this procedure applies from 0.1.0.

**Prerequisites.** Repository checked out at the version under test; toolchain and `rstd` per STP section 4.

**Steps.**

1. Run `zig build test` (toolchain per STP section 4).
2. Observe the `hs15:` tests.

**Inputs.** Start `(-2, 1)`, which violates row 1; row 2 keeps its linear term in `A`; bound `x1 <= 0.5`.

**Expected results.** Documented optimum `(0.5, 2)`, objective 306.5; `f_state[1] == nonbasic_lower`, `x_state[0] == nonbasic_upper`; `pi = 700` and `mu = -1751` within `1e-4`.

**Pass/fail criteria.** Pass when every listed test reports success. A test that reports skipped counts as a pass only while every requirement it verifies has `status: pending` in SRS; otherwise the procedure fails.

**Rerun.** Repeatable without cleanup; the procedure is deterministic and has no external state.

**Zig test names.**

- `hs15: documented optimum: objective, active set, multipliers`
- `hs15: start violates row 1`
- `hs15: analytic G matches central differences`
- `hs15: problem definition validates`
- `hs15: solve from the infeasible start`
