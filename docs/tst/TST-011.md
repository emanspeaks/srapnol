# Truss Jacobian

**Purpose.** Confirm the truss callback's analytic `G` matches central differences and includes no linear term.

**Grouping.** Test-data validation; requirements verification.

**Software version.** The version under test is recorded in the Software Test Report; this procedure applies from 0.1.0.

**Prerequisites.** Repository checked out at the version under test; toolchain and `rstd` per STP section 4.

**Steps.**

1. Run `zig build test` (toolchain per STP section 4).
2. Observe `truss: analytic G matches central differences`.

**Inputs.** The start `(5e-4, 5e-4)`, the optimum, `(1e-5, 1e-3)`, and `(5e-3, 2e-6)`; relative step `1e-4`.

**Expected results.** Declared and undeclared errors at most `1e-6`.

**Pass/fail criteria.** Pass when every listed test reports success. A test that reports skipped counts as a pass only while every requirement it verifies has `status: pending` in SRS; otherwise the procedure fails.

**Rerun.** Repeatable without cleanup; the procedure is deterministic and has no external state.

**Zig test names.**

- `truss: analytic G matches central differences`
