# Hock-Schittkowski 47

**Purpose.** Confirm equality rows that mix `A` and `G` terms in one row are handled and the quartic objective converges.

**Grouping.** Requirements verification.

**Software version.** The version under test is recorded in the Software Test Report; this procedure applies from 0.1.0.

**Prerequisites.** Repository checked out at the version under test; toolchain and `rstd` per STP section 4.

**Steps.**

1. Run `zig build test` (toolchain per STP section 4).
2. Observe the `hs47:` tests.

**Inputs.** The `hs47a.f` layout from snopt7-examples: five variables, three equality rows, objective in row 3; feasible start `(2, sqrt2, -1, 2 - sqrt2, 0.5)`.

**Expected results.** Start and optimum satisfy the rows to `1e-12`; Jacobian within `1e-6`; solve reaches objective 0 within `1e-6`, `x` within `1e-2` of all ones, rows within `1e-6`.

**Pass/fail criteria.** Pass when every listed test reports success. A test that reports skipped counts as a pass only while every requirement it verifies has `status: pending` in SRS; otherwise the procedure fails.

**Rerun.** Repeatable without cleanup; the procedure is deterministic and has no external state.

**Zig test names.**

- `hs47: start and optimum satisfy the equality rows`
- `hs47: analytic G matches central differences`
- `hs47: problem definition validates`
- `hs47: solve from the feasible start reaches all ones`
