# Scope

`srapnol` (SQP Reduced-Hessian Active-Set Partitioning Nonlinear Optimization Library)
solves sparse, general nonlinear programs with an interface modelled on `snOptA`. It is
a library, not an application: the hosting program supplies the problem, the callback
that evaluates it, and the memory. This document does not constrain the host.
