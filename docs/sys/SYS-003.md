# SNOPT compatibility

`srapnol` **shall** keep SNOPT's option names and defaults, `INFO` exit codes, and
variable-state and multiplier conventions wherever this design has a counterpart, so
that a user migrating from SNOPT obtains comparable behavior and can read `srapnol`
results with SNOPT documentation.
