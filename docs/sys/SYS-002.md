# Pure Zig implementation

`srapnol` **shall** be implemented in Zig with no dependency other than the Zig
standard library and the `rstd` package, so that it can be embedded in `rstd.linalg`
and in other Zig programs without a foreign toolchain, FFI, or third-party package.
