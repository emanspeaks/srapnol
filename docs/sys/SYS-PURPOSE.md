# Purpose

This document records the stakeholder needs and system-level requirements that
`srapnol`, a sparse nonlinear optimization library, exists to satisfy. It is the root
of the project's requirement tree: every item in the Software Requirements
Specification (SRS) links to at least one item here, which gives the higher-level to
software-requirement traceability that NPR 7150.2D SWE-052 asks of Class C software
and that this Class D project maintains so Class C applications can adopt it.
