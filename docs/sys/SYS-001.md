# Sparse nonlinear programming capability

`srapnol` **shall** solve sparse, general nonlinear programs of the `snOptA` form:
minimize one component of \(F(x)\) subject to bounds on \(x\) and on
\(F(x) = f(x) + Ax\), where \(A\) is a constant sparse matrix and the user supplies
\(f\) and the sparse Jacobian of \(f\).
