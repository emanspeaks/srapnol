# Purpose

This Software Requirements Specification (SRS) states the requirements that the
`srapnol` library is built and verified against. It is the contract between the
library and its hosts and the source of every test in the Software Test Procedures
(TST). Its content follows NASA-HDBK-2203 topic 5.09; each requirement traces up to a
stakeholder need in SYS and down to the procedures in TST and the components in DES.
