# Multiplier identity

At a reported solution the multipliers **shall** satisfy
\(\nabla F_{\texttt{obj\_row}}(x) = \sum_{i \ne \texttt{obj\_row}} \texttt{f\_mul}[i]\,
\nabla F_i(x) + \texttt{x\_mul}\).
