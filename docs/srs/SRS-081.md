# Major iteration log

With a writer set and `Options.major_print_level > 0`, the solver **shall** write one
fixed-width line per major iteration reporting the iteration number, minor
iterations, step length, evaluation count, feasibility, optimality, merit value,
number of superbasics, and penalty norm.
