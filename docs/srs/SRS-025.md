# Solution method

The solver **shall** be a sequential quadratic programming (SQP) method whose QP
subproblems are solved by an active-set, reduced-Hessian (null-space) method with a
quasi-Newton approximation of the Lagrangian Hessian, following Gill, Murray, and
Saunders (2005) as laid out in DES.
