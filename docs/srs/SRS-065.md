# Result contents

`Result` **shall** report the `Exit` value, the objective (`obj_add + F[obj_row]`, or 0
in feasible-point mode), major and minor iteration counts, function and Jacobian
evaluation counts, the count and sum of remaining infeasibilities, the number of
superbasics, and the primal and dual infeasibility measures at exit.
