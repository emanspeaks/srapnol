# Undefined evaluation exits

When step reduction cannot leave the undefined region, the solver **shall** exit
`undefined_at_initial_point` if the failure is at `x0`,
`undefined_at_first_feasible_point` if it is at the first linearly feasible point, and
`cannot_proceed_into_undefined_region` otherwise.
