# Linear feasibility first

Before the first evaluation of `f`, the solver **shall** find a point satisfying the
bounds and all linear rows to `Options.minor_feasibility_tolerance`, exiting
`infeasible_linear_constraints` or `infeasible_linear_equalities` when no such point
exists.
