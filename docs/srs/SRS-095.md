# Scalar reference kernels

Each SIMD kernel **shall** have a scalar reference implementation and a test proving
agreement to rounding on vector lengths 0, 1, \(w - 1\), \(w\), \(w + 1\), and a large
odd length, where \(w\) is the lane width.
