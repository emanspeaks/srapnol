# Elastic mode exits

In elastic mode the solver **shall** exit `nonlinear_infeasibilities_minimized` or
`infeasibilities_minimized` when the infeasibility is locally minimal, and
`infeasible_qp_subproblem` when a QP subproblem cannot be made feasible.
