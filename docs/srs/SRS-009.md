# Input validation

Before any callback is invoked, the solver **shall** reject the problem with a distinct
error for each of the following conditions: `n == 0` or `nf == 0`; a slice length
inconsistent with `n` or `nf`; a lower bound above its upper bound; NaN in any bound
or in `A`; `obj_row >= nf`; a row or column index out of range; a duplicate slot within
`A` or within `G`; the same slot present in both `A` and `G`.
