# Trace matrices

Upward traceability is the `links` attribute of every item (to SYS). Downward
traceability to design (DES) and to procedures (TST) is the reverse-link table that
Doorstop publishes for this document; traceability to code is the `references`
attribute, resolved to the citation required by the requirement on requirement
citation in section 7.
