# C callback convention

The C interface's evaluation callback **shall** have the signature
`int (*)(void *ctx, const srapnol_request *req, srapnol_response *resp)` with C
calling convention, returning 0 for success and distinct negative codes for the
undefined-point and abort conditions of the Zig interface.
