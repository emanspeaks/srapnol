# Elastic mode entry

When the linearized constraints of a QP subproblem are infeasible, the solver **shall**
switch to the elastic problem \(\text{minimize}\ f + \gamma e'(v + w)\) with elastic
variables \(v, w \ge 0\) relaxing the nonlinear rows, starting with \(\gamma = \)
`Options.elastic_weight` and increasing \(\gamma\) on repeated infeasibility up to a
fixed cap.
