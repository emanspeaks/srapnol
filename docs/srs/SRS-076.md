# C-callable interface

The library **shall** expose a C-callable interface built from `extern "C"` functions
over opaque handles, sufficient to build a `Problem` and `Options`, run `init`,
`solve`, and `deinit`, and read back `State`, `Result`, and `Exit`, as specified in the
Interface Design Description (IDD).
