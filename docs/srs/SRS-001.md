# Problem form

The solver **shall** solve `minimize F[obj_row](x) + obj_add` subject to
`x_low <= x <= x_upp` and `f_low <= F(x) <= f_upp`, where `F(x) = f(x) + A x`,
`x` is in `R^n`, `F` is in `R^nf`, `A` is a constant sparse matrix, and `f` is a smooth
function with sparse Jacobian `G`.
