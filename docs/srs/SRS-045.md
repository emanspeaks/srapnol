# Derivative verification

When `Options.verify_level` is not `.off`, the solver **shall** check `G` by finite
differences at the first linearly feasible point over the rows the level selects, and
**shall** exit `incorrect_objective_derivatives` or
`incorrect_constraint_derivatives` when the check fails.
