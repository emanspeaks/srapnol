# Vectorized dense kernels

Dense vector operations (dot, axpy, scale, 2-norm, infinity-norm, elementwise
min/max/abs, bound projection, infeasibility sums) **shall** be implemented with
`@Vector` of width `std.simd.suggestVectorLength(f64)`, falling back to scalar code
when that is null, with scalar tails.
